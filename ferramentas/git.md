# Git

Sistema de controle de versão distribuído.

## Nível

Intermediário

## Tópicos

- Comandos básicos (`init`, `clone`, `add`, `commit`, `push`, `pull`)
- Branching e merging
- Rebase e cherry-pick
- Resolução de conflitos
- Fluxos de trabalho (Git Flow, trunk-based development)
- GitHub / GitLab
