# JavaScript

Linguagem de programação leve, interpretada e orientada a objetos, amplamente usada no desenvolvimento web.

## Nível

Intermediário

## Tópicos

- Sintaxe ES6+
- Manipulação do DOM
- Funções assíncronas (`Promise`, `async/await`)
- Módulos (`import`/`export`)
- Closures e escopo
- APIs do navegador
